# Hi, I'm Christopher Adams

Inventor and systems architect building AI that runs where the data is: in devices, machines and buildings. Founder and CEO of [Kaephor](https://kaephor.com) in Dubai.

## Current Focus

**Kaephor Bridge**: edge AI gateway for buildings. A 1U rack unit with an NVIDIA Jetson on board and native field-bus interfaces (DALI-2, LON, M-Bus, RS485, KNX), so AI runs inside the building instead of in the cloud.  
**Camera-free sensing**: WiFi CSI and 60 GHz mmWave sensor fusion for presence and occupancy, without a single camera.  
**AQAI-CNA**: Adaptive Quantum AI architecture integrating MoS₂/WTe₂, MEMS-based resonance, and self-organizing learning crystals.  
**Ghyser Chip**: Ultra-fast, AI-controlled signal processing for hydrogen systems and beyond.  
**TunePeg / Robot Guitar**: Inventor of the self-tuning system in the Gibson Robot Guitar (2007), the first self-tuning electric guitar. Best of Show at the Newstips Cherry Picks event, CES 2008.  
**Manufacturing Innovation**: Built factories for micro-precision MIM gears, SMPS for audio, and medical PPE automation.
